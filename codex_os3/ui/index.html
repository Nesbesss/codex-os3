Other machines (nodes)

Other computers join OS3 with rabbit's own node installer (OS3 → Settings → add device). They don't need this router: model calls always go through the one device you picked above; tasks can still run on every node.

Models

Like OS3's own model picker: OS3's local mode sends one model for everything, so the router recognises who is asking and uses the model you set here. Small is the main chat you talk to, Standard runs the workers that carry out tasks (shell, files, computer use), Background handles memory and review calls, which run often, so a light model saves limit.
